Axiom — Visual Reference

The rendered companion to 40-design-system.md and 41-component-library.md. Every sample on this page binds the same tokens the product does, so what you see is the real value rather than a picture of it.

Status: Normative for the values it renders; where this page and the two markdown documents disagree, the markdown governs and the disagreement is a defect in this page.

This is a specification artefact, not application UI. It is not part of the product and nothing here should be shipped as a screen.

Diagrams are referenced as sibling files in diagrams/ rather than inlined, so each stays individually editable and diffable in the repository — that was a requirement of the suite, and inlining would have defeated it.

Only transform and opacity may be animated. Under prefers-reduced-motion every duration collapses to 0.01ms; the force simulation is not currently gated by it, which is recorded as a defect.

Icon set

One outlined family, 1.5px stroke, 16px and 20px sizes. Filled and outlined are never mixed at the same hierarchy level, and emoji are never used as functional icons.

Five symbols are defined and not yet referenced — i-pin, i-expand, i-collapse, i-trash, i-filter — and i-check currently carries two unrelated meanings (query success, and commit rename). Both are recorded in the design-system document.

Entity encoding

Shape carries the kind; colour reinforces it. A reader with any common colour-vision deficiency, or a greyscale print, loses nothing. See Figure 19 for radii and the decoration layer.

Buttons

The danger-primary variant exists because the reference build applies an inline style="background:var(--danger)" to a primary button in the delete dialog, breaking its own no-hard-coded-values rule. This variant is the specified replacement.

Fields & selects

Names cannot contain spaces — use CamelCase, as the rest of the ontology does.

Labels are persistently visible; a placeholder never stands in for one. Validation runs on blur, and every message names the cause and the remedy.
