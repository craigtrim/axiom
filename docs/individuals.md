# Individuals and Inspector

Individuals computes its columns from the selected class's statements. The Individual column is always visible. Columns shows fill, distinct values, multivalue depth and the reasons a column is initially hidden. All, None and Reset affect this layout; None keeps Individual, and Reset restores computed defaults, order and widths.

Filtering uses Find's shared ranked search over shown columns and each subject's local name. Show `rdfs:seeAlso` to search those aliases; hidden aliases and the hidden IRI namespace do not match. Partial words, filler words, misspellings and reordered words work as they do in Find. Lexical results arrive immediately; the local MPNet model adds meaning-based results after typing pauses, when installed. A missing model leaves lexical results usable. Class selection scopes the same grid to direct instances before matching and ranking.

An active query uses best-match order until a column sort is explicitly chosen. With an empty filter, rows follow the column sort, initially Individual ascending. Clicking a header sorts the results and clicking it again reverses the order. Explicit column sorts are saved with the workspace. Blank values sort last in either direction; numeric columns sort numerically. Multiple values show their first value and a keyboard-accessible `+n` popover. Subjects without a label show their local name with an `id` tag.

The generated example's class instance report uses the same ranked search over names, aliases and IRIs. It includes only the selected class's direct named and generated instances, pages at 100 rows, and lists every direct instance when the filter is empty. Both filters keep completed rows visible during replacement searches and ignore obsolete lexical or semantic replies. The hierarchy continues to show classes only.

Drag any header to reorder columns, including Individual. The first shown column is pinned. The chooser also offers Move earlier/later controls on hover or keyboard focus and retains focus after each move. Drag a separator to resize, or double-click to autofit the current page. Focused separators accept Left/Right (8 pixels), Shift+Left/Right (32), Home (default width), and Enter/Space (autofit). Widths stay between 56 and 720 pixels. Visibility, order and widths are saved per class in the workspace.

Up/Down select rows across page boundaries. Home/End select the first/last row on the page; Page Up/Page Down turn the page and select its first row. The selected row takes keyboard focus and scrolls into view. Clicking a row does not move its columns or scroll position. Escape closes a chooser or values popover and returns focus to its opener. Opening a cell's value list preserves the selected row.

New individual uses the existing creation flow. A new individual in the current scope clears the filter and reveals its selected row on the correct page. Creating an individual in another class leaves the current scope and filter intact. The pager accepts a page number, clamps it to the available range and returns to page 1 for invalid text. Clear the filter also returns to page 1 and focuses the filter.

Below 600 pixels, the toolbar wraps and keeps the class choice visible. The chooser keeps column names whole and truncates tags when needed. Recovery below 240 pixels wide or 120 pixels tall preserves the pane's working state. The dock controls its size; the pane has no separate resize grip.

Inspector shows every asserted predicate and groups its values, including inferred values marked read-only. Groups with more than three asserted values initially show three. Add value expands the group and focuses the new value; expansion survives selection changes. Add statement opens the predicate menu, with predicates already in the draft disabled. The action row carries the save state. Apply changes merges the draft in one Undo operation; Discard or Escape abandons it. Changing selection preserves drafts, and typing during Apply remains a draft after that save finishes. Conflicts retain the edit and identify the predicate.

Name edits the same preferred label shown in the statement table and validates immediately. More actions offers Copy IRI and Find touchpoints. As the pane narrows, Add statement, Open in Details and Discard move there in that order; Apply stays visible. Class usage shows subclasses, descendants, direct instances and uses as a value. Individuals show draft types and statements, uses as a value and distinct referencing subjects. Properties show subproperties and uses as a predicate. Other kinds show uses as a value. Zeros remain visible. Usage withdraws in shallow panes, and the IRI withdraws in narrow panes. Inspector uses shared recovery thresholds and retains the draft and validation behind Maximize pane (issue #89).
