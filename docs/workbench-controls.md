# Workbench controls

The Windows title band is 36 CSS pixels high, with the app mark, eight menus and a document pill. The pill shows the filename in bold, an asterisk for unsaved changes, and the folder; clicking it opens the command palette. Open workspaces use the workspace path; imported ontologies use their source file path until a workspace is saved. Unsaved documents show their name without an invented path. The native window title remains **Axiom | absolute path**, followed by ` *` when dirty, for the taskbar and screen readers. Windows retains the native minimize, maximize and close controls; their reserved area comes from Electron's title-bar environment variables, and their colors follow the current theme.

Find is available through **Edit > Find** or **Ctrl+F**. Its compact modal focuses the search field and offers type-ahead matches. Enter or a match opens the full results in the dockable **View > Find** pane. New class, New individual, Undo, Redo and Save are available from their menus, context actions and keyboard shortcuts. The document pill, **View > Command palette** and **Ctrl+Shift+P** open the palette. **Edit > Keyboard shortcuts** provides remappable shortcuts and menu access keys.

The title band's folder withdraws at 1100 CSS pixels, the menus fold into Application menu at 820, and the pill withdraws at 620. The window retains its 840×600 minimum; View > Zoom in reaches the smaller CSS widths. Bare Alt or F10 focuses the menus. Alt plus an access key opens its popup, arrows move through menus and items, Escape returns one level, and Tab leaves the menu. Disabled items accept focus but cannot run. Long popups scroll within the window. Detached panes retain their native F10 application-menu popup and have no custom title band.

In Details, the predicate list starts with the entity's existing predicates in their displayed order, without duplicates. Other predicates follow. `rdf:type` is not offered in the dropdown; existing type declarations remain in the grid.

Annotation values such as `rdfs:seeAlso` accept text and offer matching resources through typeahead. The first option shows the typed text in quotes above **Store a text value**; choose it to store that text. Click a resource match, or highlight one with the arrow keys and press Enter, to make a link. Typing again clears the highlight and pointing at a match does not highlight it, so Enter with nothing highlighted keeps the typed text unless the row already holds a link and the text exactly names a resource. Editing an existing text value preserves its language and datatype. New rows use the existing predicate's value type where available. Workspace saves retain unfinished rows and unapplied source edits as drafts. Complete grid edits are applied when using File > Save; source edits still require their own Save source or Apply changes action. <!-- craigtrim/axiom#35 -->

The Find pane provides one ranked search with immediate lexical results, entity-type and field filters, sorting, recent searches and pagination. It retains its query and filters when reopened or restarted. Clear and Recent searches live inside the search field. More contains Results per page (25, 50, 100 or 200; default 50) and the selected result's Details, taxonomy navigation, graph actions and Copy IRI. Scope appears as a rail or through Options with visible field/type counts. Reset filters restores the default name/IRI scope, all types and Best match while keeping the query. Searching itself leaves the graph unchanged. Source and query editors retain their local Ctrl+F behavior.
