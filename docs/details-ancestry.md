# Details ancestry and row editing

Details shows one ancestry trail above the statement grid. Each class appears once, with shared ancestors grouped into a single stage and roots at the end. For example, Basic English leads to English Language, then a group containing English and Language, then Course.

Wide panes place the selected entity on the right and lead left toward the roots. Tall panes start with the selected entity at the top and lead downward. The orientation follows the pane dimensions when docked, detached or resized. Ancestor names open their Details; Back returns to the previous selection. Selecting an ancestor also reveals its taxonomy row, clears a filter that would hide it and aligns the row with the newly selected ancestry card. When that horizontal alignment is unavailable, including detached windows, the row centers in the taxonomy viewport. Scrolling respects the list boundaries and pane zoom, keeps focus in Details and leaves ordinary taxonomy clicks at their current scroll position.

The trail groups ancestors by their nearest distance from the selected entity and combines roots into the final stage. It summarizes ancestry rather than drawing every inheritance route. Hover a card to inspect its recorded parent relationships, including instance membership and parents from intersection definitions. The view uses the existing taxonomy projection and preserves the underlying RDF. Cycles terminate without repeating a class or presenting the cycle as a root.

Trails with more than five stages fold their middle stages behind a count. Choose the count to reveal them in a scrollable trail. Groups initially show up to four names and offer a control to reveal the remainder. Traversal initially loads up to 2,048 unique entities; a control loads more when needed. Unresolved references are identified in card tooltips. A class with no recorded named parent appears as a root without adding an assertion to owl:Thing.

The statement grid has one **+ Add row** control beneath its rows. It adds a blank row and focuses the predicate dropdown. Select a predicate, then enter a literal value or use the existing resource typeahead. Cell edits save automatically. An unfinished row can be removed with its row action; repeatedly choosing Add row focuses an existing row that still needs a predicate. The fixed class declaration remains read-only.
